# qa-engineering-portfolio

Product-minded **Quality Engineer / SDET** focused on SaaS and AI product quality.

This repo collects my hands-on QA & test automation work: manual test packs,
a Playwright + TypeScript framework, API & database testing, accessibility,
performance, security, and AI product evaluation.

## About me

I'm Mabel Okeke, a Senior Product Designer with 7 years of experience across
fintech, logistics, e-commerce, e-learning, social networks, mobility, and
blockchain. As a designer, I see the whole business problem, not just the
interface, I understand user research deeply enough to know when people are
lying about what they need, and I can take a mess and turn it into a clear
system.

My current workflow involves prototyping directly in code using Claude Code,
Codex, Antigravity, and Cursor, so I can test how something actually works
before it goes to engineering. That habit of testing my own work before
handoff is what pulled me toward QA Engineering. I'm not just able to design
and build a product, I can also run a rigorous analysis of each flow and
functionality to make sure it holds up against real user needs and business
goals before it reaches real users.
